# Tham chiếu thiết kế

`design-tokens-reference.json` lưu nguyên bản bảng token thiết kế trước đây.
File này không được giao diện đọc lúc chạy và không phải nguồn màu hiện hành.
Giao diện dùng CSS variables trong mã nguồn web; không tự động đồng bộ hay ghi
đè CSS từ JSON tham chiếu này.

Nguồn CSS hiện hành: `apps/web/src/shared/styles/tokens.css`.

Danh mục ảnh và minh họa nằm trong `apps/web/public/assets/README.md`.
