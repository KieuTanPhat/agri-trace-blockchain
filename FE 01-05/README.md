# Agri Traceability Blockchain Frontend

Workspace cho đồ án hệ thống truy xuất nguồn gốc nông sản ứng dụng blockchain.

## Deliverables tuần này

- User flow 4 nhóm role: `docs/user-flows.md`
- Wireframe v1: `docs/wireframes.md`
- Next.js/PWA skeleton: `apps/web`
- Mock API contract + shared components: `apps/web/src/lib/mock-api.ts`, `apps/web/src/components`
- IoT simulator proposal: `docs/iot-simulator-proposal.md`

## Chạy frontend

```bash
npm install
npm run dev
```

App chạy mặc định tại `http://localhost:3000`.
