# AgriTrace Figma Asset Pack

## Nội dung
- `brand/agritrace-logo.svg`: logo vector.
- `brand/leaf-pattern.svg`: nền mint và họa tiết lá.
- `icons/`: hơn 70 icon SVG cho dashboard, form, QR, IoT và thao tác.
- `images/hero-supply-chain.png`: minh họa hero chuỗi cung ứng.
- `images/auth-farm-flow.png`: minh họa trang đăng nhập.
- `images/trace-product.png`: gói rau cho trang truy xuất.
- `images/process-5-steps.png`: bộ minh họa 5 bước để crop trong Figma.
- `images/technology-ecosystem.png`: hero trang Công nghệ.
- `images/qr-scan-photo.png`: ảnh quét QR.
- `images/business-registration.png`: ảnh trang đăng ký doanh nghiệp.
- `certificates/`: 3 chứng nhận mẫu dạng SVG.
- `states/`: minh họa lỗi 403, 409, 422 và 503 dạng SVG.
- `components/`: bản đồ hành trình, biểu đồ IoT, donut tuân thủ và avatar cho 4 role.
- `design-tokens.json`: bảng màu, bo góc, font và shadow.

## Dùng trong Figma
1. Giải nén file ZIP rồi kéo SVG hoặc PNG vào canvas.
2. Với icon SVG, đổi Stroke thành #166534 hoặc #22C55E.
3. Với ảnh PNG có nền caro, dùng plugin Remove BG để tạo alpha trong suốt.
4. Crop `process-5-steps.png` thành 5 ảnh vuông bằng Frame + Clip content.
5. Dùng font Be Vietnam Pro hoặc Inter và màu trong design-tokens.json.

## Kích thước gợi ý
- Icon sidebar: 20–22 px.
- Icon KPI: 28–32 px.
- Logo header: rộng 150–180 px.
- Hero illustration: rộng 620–720 px.
- Ảnh gói sản phẩm: 420–520 px.
